## Task Name:Tailwind Hero Landing Page
A modern and responsive AI productivity landing page created using **HTML, CSS, JavaScript, and Tailwind CSS CDN**.

## 🚀 Features

- Sticky navigation bar
- Product, Solutions, Resources, Pricing and Login navigation links
- "Get AI free" CTA button
- Hero section with gradient background
- Main heading and description
- "Get AI free" and "Request a demo" buttons
- Dashboard preview image
- Floating Tasks card
- Floating Project Status card
- Floating Team Activity card
- Fixed chat widget
- Responsive design for desktop and mobile
- Tailwind CSS positioning utilities

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS CDN
